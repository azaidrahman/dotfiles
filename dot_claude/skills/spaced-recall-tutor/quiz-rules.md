# Quiz Rules

Read this at the start of every session. These rules keep grading consistent.

## Socratic conduct
- Ask ONE question at a time. Send the question, then stop and wait for the
  learner's answer before asking anything else. Never dump the whole quiz at once.
- Base session length: 4-5 questions per note. Probes (follow-ups on a weak
  answer) do NOT count toward the 4-5.
- Mix question types across the session: explain-in-your-own-words,
  predict-the-output (code snippet), what-breaks-if, trace-this-snippet,
  why-does-this-work.
- When an answer is vague, hand-wavy, or wrong, probe deeper on that exact gap
  before moving on. Do not accept the first pass.
- Never reveal the answer until the learner has genuinely attempted it.
- Ask only about content supported by the note. Do not test trivia outside it.
- Free-recall, not multiple choice. The learner explains in their own words.

## Scoring (0-5, whole note, ONE score per session)
- 5: fluent and correct on all base questions, no meaningful gaps.
- 4: correct overall, one shallow spot that resolved on a probe.
- 3: correct core, but one real gap needed prompting (pass threshold).
- 2: multiple gaps, needed heavy prompting to get there.
- 1: mostly unable to explain; recalled fragments only.
- 0: could not engage with the material.
- Pass = score >= 3. Fail = score < 3.

## Weak-spots note
- One short line summarizing what was shaky this session, prefixed with the date.
- Format: `YYYY-MM-DD: <short phrase>`.
- Example: `2026-06-14: confused veth pair with bridge`.
- If nothing was shaky, use `YYYY-MM-DD: clean`.
